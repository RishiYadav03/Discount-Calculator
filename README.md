# Discount-Calculator

The Discount Calculator is a user-friendly, responsive web application designed to help users compute the final price of an item after applying a discount. Built with HTML for structure and Bootstrap for styling and layout, the tool features:

Clean and responsive design using Bootstrap grid system and components.

Input fields for original price and discount percentage.

Instant calculation of discounted amount and final price.

Bootstrap form controls for a modern, accessible interface.

Optional: Validation and alerts for invalid or missing inputs.

This tool is perfect for online shoppers, small business owners, or anyone who needs quick price calculations without using a calculator.
